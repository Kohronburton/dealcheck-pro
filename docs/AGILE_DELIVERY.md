# Agile Delivery System

## Cadence

One-week sprints with a potentially sellable workbook increment at each sprint review.

## Roles

- Product Owner: Kohron Burton
- Build and QA: repository contributors
- Customer voice: new and intermediate residential investors

## Definition of Ready

A story is ready when it has a user outcome, inputs, expected outputs, acceptance criteria, formula notes, edge cases, and dependencies.

## Definition of Done

- Acceptance criteria pass
- Representative formulas are inspected
- Formula-error scan is clean
- Model checks show OK or a documented limitation
- All changed sheets receive a visual render review
- Excel export opens successfully
- Google Sheets compatibility is assessed
- User-facing documentation is updated
- No sensitive data or credentials are committed

## Sprint sequence

| Sprint | Goal | Increment |
|---|---|---|
| 0 | Foundation | PRD, architecture, scoring rules, QA strategy, backlog |
| 1 | Fast decision MVP | Quick Mode, Financing, Rental, Flip, Wholesale |
| 2 | Explainable decision | Dashboard, Strategy Battle, Deal DNA, Buy Box |
| 3 | Advanced exits | BRRRR, STR, capital stack |
| 4 | Negotiation intelligence | Offer Optimizer, Deal Rescue, Risk Radar |
| 5 | Downside protection | Stress Lab, Survival Price, backup exits |
| 6 | Execution system | Tracker, due diligence, investor memo |
| 7 | Commercial release | compatibility QA, docs, packaging, Etsy assets |

## Ceremony checklist

### Sprint planning

Select stories that form one coherent user journey. Confirm acceptance criteria and test fixtures before formula work.

### Daily execution

Keep the workbook executable. Commit source changes in small, reviewable increments. Record formula decisions in the architecture notes.

### Sprint review

Demonstrate the workbook with a worked property and at least one failing deal. Confirm that the recommendation is explainable.

### Retrospective

Record confusing inputs, defects, support risks, scope changes, and one improvement for the next sprint.

## Release gates

1. Calculation integrity
2. Usability and onboarding
3. Visual quality
4. Excel compatibility
5. Google Sheets compatibility
6. Print/PDF fidelity
7. Disclaimer and license presence
8. Version/changelog update
