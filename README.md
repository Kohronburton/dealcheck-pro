# DealCheck Pro

DealCheck Pro is a residential real-estate deal decision system for Excel and Google Sheets.

It is designed to let an investor enter a property once, compare multiple exit strategies, stress-test the assumptions, calculate a safe offer range, and produce an investor-ready decision memo.

## Product promise

Analyze a property in under five minutes, uncover hidden risks, identify the strongest strategy, and know what must change for the deal to work.

## Development

This project uses Agile delivery with shippable workbook increments, visible acceptance criteria, formula-level testing, and Excel/Google Sheets compatibility gates.
